# K-12 AI 素養國際動態｜週報與月度趨勢

公開網站以 GitHub Pages 靜態部署。每日蒐集國際政策及研究動態；自 2026 年 10 月 12–18 日起，每週產出 K-12 AI 素養國際動態週報，並於月底另發布跨週趨勢總結。

- 網站首頁：`index.html`
- 週報：`weekly/YYYY-Www/index.html`（首期預計 2026-10-19 發布）
- 月度趨勢總結：`monthly/YYYY-MM/index.html`（後續以標題區分趨勢總結）
- 2026 年 9 月歷史月報：`monthly/2026-09/index.html`（保留原網址及內容）

每期報告皆須核對原始來源、日期、政策適用範圍、重要數字及引文；完成後方可公開發布。尚未生成的報告不應建立虛假頁面。

GitHub Pages：Settings → Pages → Deploy from a branch → `main` / `(root)`。
