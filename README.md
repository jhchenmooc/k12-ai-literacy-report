# K-12 AI 素養國際動態月報

GitHub Pages 靜態網站，供臺灣 K-12 AI 素養政策、研究與教學參考。

- 網站首頁：`index.html`
- 2026 年 9 月月報：`monthly/2026-09/index.html`
- 版本：v1.1（2026-10-08）

## 發布

Settings → Pages → Deploy from a branch → `main` / `(root)`。

## 更新方式

每月新增 `monthly/YYYY-MM/index.html`，並在首頁增加當月入口。請於發布前檢查原始來源、引用文字、時間與學段適用範圍；避免把政策建議寫成已實施政策。
