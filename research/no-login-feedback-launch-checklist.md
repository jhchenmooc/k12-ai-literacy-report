# 免 GitHub 登入回饋：安全啟用清單 v0.1

## 目前狀態

> **停用中（2026-10-09 管理者決策）**：此檔僅保存未來另案核准重啟時的安全清單，並非目前啟用工作。請先以 [讀者回饋 SOP](reader-feedback-policy.md) 的最後「Google 表單暫停」段落為準；不得因本清單記載操作步驟就更改現行配置或進行外部收件測試。

網站 `feedback/no-login/` 已提供說明與安全停用狀態。GitHub Pages 為靜態託管，不提供匿名表單接收 API。**未指定真正的收件服務之前，不能接收資料**。網站保留既有 GitHub Issues 公開勘誤管道。

## 啟用外部收件服務所需設定

建議由管理者自行建立**獨立的 Google Form**，避免把個人 Email 或私人資料庫金鑰放入公開 repo。表單欄位建議：

- 報告網址（必填）
- 回饋類別（勘誤／來源與政策解讀／易讀性／建議）
- 內容可信度感受與易讀性（1–5、未評分）
- 段落及回饋說明（選填）
- 參考來源 URL（選填）
- 不要求姓名、Email、學校、班級、學號等個人資料

**Google Forms 設定核對：** 勿限制為單一機構、不要強制登入或自動收集電子郵件（若服務政策容許），避免要求上傳檔案；測試未登入狀態是否真能提交。未登入不代表匿名，Google 與網路服務供應商仍可能處理存取中繼資料。

資料保留與存取權：限定管理者，刪除不必要個資，設定合理的保留期限；只發布聚合數量、問題類別及去識別的修正紀錄。不得直接把私人回饋全文鏡像到公開 GitHub Issues。

管理者需確認個資聲明可供讀者查閱，再編輯 `feedback/no-login-config.js`：

```js
window.K12_FEEDBACK_CONFIG = {
  publicFormUrl: "https://forms.gle/<PUBLIC_FORM_ID>",
  privacyNoticeUrl: "https://<PUBLISHED_PRIVACY_NOTICE_PAGE>",
  provider: "Google Forms"
};
```

僅可使用公開填答網址（Google Forms `viewform` 或 `forms.gle`），不得使用編輯者網址、OAuth Token、API key 或私人資料。網站開啟表單採外部頁面，不在本站代送資料。

## 上線前必做測試

1. 未登入 GitHub、未登入 Google 的乾淨瀏覽器，確認表單可填寫並送出一筆**不含真實個資的測試資料**。
2. 管理者於 Google Forms 收件端確認收到且內容相符，然後刪除測試資料。
3. 在手機及鍵盤模式測試文字、表單跳轉與返回。
4. 查看公開回饋入口是否載入指定表單，但不能在讀者頁面顯示管理權限或金鑰。
5. 驗證 GitHub `verify` 通過、合併及 Pages 部署成功。
6. 週整理預設**只統計公開 GitHub Issues**；私有 Google Form 回應不會自動出現在既有公開週整理。需要自動合併統計時，應另設只讀聚合橋接流程及授權，不可以公開私人逐筆回饋。

## 不能宣稱的事項

- 未填 URL 前：不能宣稱免登入入口已能收件。
- 已填 URL 但未做外部測試：不能宣稱讀者能免登入實際提交。
- 免登入：不等於端到端匿名或零個資處理。
- GitHub Pages 沒有服務端驗證；垃圾訊息與內容處置取決於表單供應商及維護者設定。
