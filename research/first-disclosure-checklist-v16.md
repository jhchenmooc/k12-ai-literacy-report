# v1.6 首發與來源忠實核查表（先篩再寫）

此表為既有 SOP 的操作摘要，不是新核准機制。**開始前先檢查同週及歷史候選 JSON 的 URL、DOI、event_key、hold 原因，尤其 A07 撤稿紀錄。**

- [ ] **辨認資料身分**：官方具效力政策／指引／草案／評論／活動；研究為同儕評議論文／預印本。辨認國家、K–12 學段、適用對象。
- [ ] **分開核對四種日期**：事件或生效日、同事件最早公開日、所引文件首發日、本刊發現日。另記網頁更新日、預印本／online first／期刊卷期日；不能把更新或活動日當首次發表。
- [ ] **事件去重與更早反證**：查本期和往期候選（URL／DOI／事件鍵），再查原機構較早版本、其他語言新聞與論壇、正式機關文件。**已找到更早同事件報導，先維持 hold。**
- [ ] **逐句原文核對**：留下原始網址、發布者、可定位短摘錄與版本；將中文摘要每個數字、學段、政策效力、研究結果與限制對回原文。第一輪擷取，第二輪主動找反證、例外、研究設計與更早公開。
- [ ] **是否准許刊登**：日期缺失、來源衝突、範圍與翻譯不清、無法核實 DOI 或高風險外推，一律 hold。可刊者才由同一候選池核對狀態，建立 snapshot／claims／HTML／issues 和來源連結。
- [ ] **不把 CI 當內容認證**：PR verify → main verify → Pages deploy → 外部頁面與原文連結驗收，分別記錄；0 則可不發刊。已刊但出現首發反證須撤回／勘誤，保留 PR 歷史。

日期決策：當前七日新訊門檻是**必要但不充分**，不能只檢查文章距出版日 ≤7 天。若同一事件在週期前公開，新的翻譯稿／網頁更新不使舊事件重新變成新訊。原始文件若真正新增獨立政策事實，須另列其新內容證據。
