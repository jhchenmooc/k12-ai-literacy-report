# K-12 AI 素養：新聞與期刊誤讀壓力測試 v0.1

日期：2026-10-08。這是**人工設計的暫定標籤測試**，並非不同真人專家獨立完成的原文事實查核。

## 測試集與方法

使用創刊特刊四則新聞、一則背景活動及五個學術研究主題，共十組；每組建立一個謹慎且有限定條件的敘述、一個明顯誤讀和一個隱晦過度推論，共 **30 個合成句子**。其中 20 句暫定為不支持／不可直接刊登、10 句暫定為有條件支持。

本測試資料依既有報告的來源摘要與研究候選整理，**尚未由兩名真人獨立重新對照所有原始全文**，故資料標籤稱為 provisional editorial labels，不能當作黃金標準。抽樣與命題亦非隨機，沒有代表性。

基準程式 `research/benchmark-semantic.js` 利用固定中文警示詞辨識跨範圍推論、因果誇大、正式政策效力等疑點；**無論警示結果為何，均輸出 decision=review，不會自行允許正式刊登**。

## 可重現的初步基準

| 指標 | 結果 |
|---|---:|
| 合成案例 | 30 |
| 應予警示（暫定） | 20 |
| 可有條件敘述（暫定） | 10 |
| TP：正確警示 | 18 |
| FN：錯誤主張漏警示 | **2** |
| FP：合宜敘述誤警示 | 1 |
| TN：合宜敘述未警示 | 9 |
| 漏警示率 FN/(TP+FN) | **10%** |
| 誤警示率 FP/(FP+TN) | **10%** |

漏警示案例：

- `N01-SUBTLE`：把研究者對框架治理的批判推成國際框架已失去教師專業自主。
- `N04-SUBTLE`：把兩位肯亞教師敘事推成非洲所有 K-12 的一般教育成果。

這兩個保留下來作為**現有規則無法辨識隱晦錯誤推論**的警示案例，不以修改答案方式提升分數。

**切勿誤解：** 10% 是這份人工合成資料上的「關鍵字漏警示率」，**不是**公開週報的實際錯誤率，更不是具專家黃金標準的 AI 語意審稿錯誤率。由於工具從不自動批准，不能將此比例稱為錯誤自動放行率。

## 後續真正的驗證條件

1. 由至少兩位**不同真人審查者**，各自閱讀官方新聞、研究全文及上下文，對這些主張獨立標記「支持／部分支持／不支持／不能判定」。
2. 保存每句的來源位置、出版日期、適用對象／年級、主張類型、測量結果、研究與政策效力限制。
3. 分歧交第三人處理，不將無法判定硬歸類為正確；另建立未被用於調整規則的盲測集。
4. 屆時再計算語意審查的漏判率、誤判率、重大政策錯誤的加權漏判率，並將結果與本合成基準分開呈現。

目前語意警示模組為**輔助風險提示，不作為發布通過依據**。真實正式發布仍需先前的 claim_id、原文快照、SHA-256、逐項來源與必要人工核對。
