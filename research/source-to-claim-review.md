# 原文證據快照與中文解讀雙層查核 v1.0

適用於新建週報、月報；歷史版本不自動升級為核實狀態。

## 機械式第一層（由 CI 拒絕）
原有的「正文 data-claim-id → claim_text」一致性檢查保留。新的 substantive claim（descriptive/high_impact）還須包含：

| 欄位 | 定義 |
|---|---|
| evidence_path | publication/sources/<id>.txt 或 .md |
| evidence_sha256 | 該 UTF-8 原文快照內容的 SHA-256（不是網址雜湊） |
| original_excerpt | 在來源快照中**逐字存在**的原文摘錄，不要編造引文 |
| evidence_source_url | 必須與 source_url 相同的來源位置 |
| assertion_type | direct_statement、research_finding、author_opinion、editorial_analysis |
| interpretation_note | 編輯為何如此理解，以及該敘述與證據的對應 |
| scope_limitation | 哪些地區、學段、研究方法或日期不能外推 |
| translation_reviewed | 是否已真正做過原文／譯文對讀，不得為讓測試通過而設 true |

快照不是從網路自動下載，必須取得授權且可核對的原始文字。**請保留最短足以檢查的摘錄與必要周邊脈絡，避免大量轉載受著作權保護的全文。** 原文快照本身也可能由 AI 不實填寫，因此上述條件只能證明「JSON 摘錄與倉庫快照一致」，不證明快照真實來自發布者。

## 人工／獨立第二層：語意查核表

校對者閱讀官方頁面、原文附近至少一段上下文，逐題確認：

1. **發布者與效力**：正式法規、行政建議、政策提案、會議報導、研究作者評論有無混淆？
2. **時間與時態**：發布、更新、活動、預定與實際生效時間是否各自標示？
3. **地區與對象**：全國、州縣、單校、K-12、師資生、大學生是否正確？
4. **情態詞**：may/could/should/proposed/pilot 等有無被翻成必須、已全面實施？
5. **統計與因果**：樣本數與分母、主觀感受與客觀表現、短期結果與長期遷移有無混用？
6. **作者主張 vs 本刊推論**：評論者的批判不等於被評論機關承認；編輯建議不能冒稱政策規定。
7. **限制與反證**：反例、例外、更新公告及不同意見是否被刻意省略？
8. **充分依據**：摘錄是否截斷上下文而讓中文敘述產生相反意思？重要主張至少要檢查完整脈絡。

審閱結論採「支持／部分支持需修改／不支持須暫緩／證據不足」。高影響的正式政策解讀需要**真的由不同真人審閱者**確認，並留存查核位置；無審閱者就降級或暫緩，不得假稱多個 AI 角色已獨立通過。

## 回歸測試界線
Node CI 會拒絕缺摘錄、被修改的快照、錯來源連結與遺漏解讀紀錄；這些是**格式完整性與可追溯性測試**。它目前沒有利用 LLM 判斷語意是否一致，也不會自動連網驗證來源真偽。通過 CI 不等於真實性或翻譯的獨立認證。

若無法取得可合法留存的原文摘錄，應先維持內部候選，暫不發布效果、重大政策變化或 K-12 外推結論。
