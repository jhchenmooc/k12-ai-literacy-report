讀者回饋資料處理說明

回饋管道與資料

本網站使用 Google Forms 接收免 GitHub 登入的意見。可能包含讀者自填的報告網址、類別、可信度感受／易讀性評分、問題段落、改善文字及來源網址。請勿填入姓名、電子郵件、學生個資、學校內部資料或敏感文件。Google Forms 是否自動收集電子郵件、是否要求登入，以及收件者權限，應以表單的實際設定及測試為準；本站尚未完成端到端驗收。

目的與對外揭露

回饋用於辨識勘誤、排序查核及改善網站。私人 Google Forms 逐筆回覆不應自動公開於 GitHub Issues；對外只應提供聚合數量、類別、有效評分數或經適當去識別的更正資訊。讀者評分是自願提供、非代表性樣本，不可當作內容經專業事實查核或研究有效性的證據。

平台與限制

填寫及送出時將離開本網站進入 Google 表單，Google 可能依其服務條款處理網路與操作資料。詳見 Google 隱私權政策。本網站的 GitHub Pages 靜態頁面不自行接收表單內容；它無法保證第三方服務的匿名性與保存期限。

表單管理者應限制存取人員並定期檢視留存必要性。在管理者公布具體保留期限和私下聯絡途徑前，本站不保證固定刪除期限或提供不具依據的隱私承諾。

勘誤處理

來源真偽、政策效力或研究因果問題，應於修改報告前重新核查原始來源；如需要公開更正，應只公布必要且去識別化的處理摘要。另有公開 GitHub Issues 管道，但該管道須登入，帳號與文字內容均公開，不適合提交機密資料。
