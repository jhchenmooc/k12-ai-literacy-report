讀者評鑑與勘誤

幫我們發現新聞解讀錯誤、論文證據問題，以及更好的呈現方式。

提交評鑑或勘誤

您可以對週報、月報的內容可信度感受與易讀性各評 1–5 分，也可以提出具體勘誤。純評分不用填長篇文字，但需要提供報告網址；評分反映個人感受，不是專業事實核查結果。

填寫讀者評鑑／勘誤表 ↗

回饋透過 GitHub Issues 收集，必須登入 GitHub；帳號名稱、表單內容和留言皆公開。若不想公開身分，請勿使用此表單提交隱私或敏感內容。這個網頁不會在您按鈕前自行送出資料。

我們最希望收到的回饋

  • 事實正確性：來源、國家、公布日與實施日是否有誤？
  • 政策解讀：是否把建議、試辦、評論寫成強制法規？
  • 學術研究：是否把相關當因果、把大學生結果套用到 K-12？
  • 證據來源：是否遺漏重要原文、引用錯誤或連結失效？
  • 閱讀品質：哪些地方不清楚、資訊過多或手機不易使用？

回饋如何轉為實際改善？

  1. 回饋會成為公開 GitHub Issue，可供查閱和追蹤。
  2. 每週一彙整自願回饋的筆數、類別與有效評分人數；週整理只引用 Issue 編號，不重複轉貼讀者文字。
  3. 一般意見依優先程度追蹤；明確疑似重大政策、事實錯誤或個資問題應及早回報，不須等週整理。原始來源未核實前不改成確定結論。
  4. 需要修正時透過 GitHub Pull Request、CI 檢查及正式部署；重大勘誤公開保留更正紀錄。

您可查看 GitHub 公開回饋紀錄 ↗。評分屬自願提供者的主觀回饋，不能當作新聞或研究已獲驗證的證據。

隱私及品質說明

請勿提交任何學生、未成年者或其他人的個資、非公開學校資料或敏感文件；避免直接貼上身分可識別的截圖。GitHub 帳號名稱與公開留言會出現在 Issues 中，週整理雖只放連結仍可通向原公開內容。這是公開回饋渠道，不是匿名或機密申訴管道。

讀者回饋可協助發現錯誤，但不代表每一則意見都已經過獨立查核；重大修正仍須逐項追溯原始資料。
