Google 表單讀者回饋

讓教師、家長及一般讀者不必註冊 GitHub，也能參與報告改善。

免登入表單尚未開放

目前尚未設定表單接收服務，因此這個頁面不會收集或送出您的資料，也不會顯示假的「提交成功」。

如有需要立即提出公開勘誤，請使用 GitHub 讀者回饋表單（需登入）。

可以回饋什麼？

可以針對特定報告提供可信度感受、易讀性評分，或指出日期、政策效力、因果推論、學段適用性、原始來源與連結問題。

建議只附報告網址與問題所在段落；不要提供學生姓名、個人聯絡資料、班級名單、未公開文件或可識別他人的截圖。

讀者評分是自選樣本，不代表報告的客觀正確率。未經原始來源查核的勘誤不會被當成已確認事實。

回饋會如何處理？

本站已提供第三方 Google 表單連結；實際是否需登入、能否收件仍待外部驗收。不同於公開 GitHub Issues，免登入表單內容原則上不直接公開；定期報告只應使用去識別化、彙總後的統計。

若尚未同意第三方資料處理條件，請不要在外部表單輸入資訊。

本站為 GitHub Pages 靜態頁面；目前不設 Cookie 或自行接收表單內容。Google 表單位於外部網站，須由表單管理者核實提交與收件、登入限制及防濫用設定。
